# TypeScript 最佳实践

**来源**: TypeScript 官方文档 + 微软工程实践  
**日期**: 2026-05-06  
**作者**: 蜜蜂 CTO

## 1. 严格模式 (Strict Mode)
- ✅ **开启 `strict: true`**：在 `tsconfig.json` 中启用所有严格检查。
- ✅ **禁止 `any`**：除非万不得已，否则禁止使用 `any` 类型。
- ✅ **显式返回类型**：所有函数必须声明返回类型。

## 2. 类型安全
- ✅ **Interface vs Type**：优先使用 `interface` 定义对象结构，`type` 定义联合/交叉类型。
- ✅ **泛型约束**：使用 `extends` 约束泛型，避免类型丢失。
- ✅ **工具类型**：熟练使用 `Partial`, `Pick`, `Omit`, `Record` 等工具类型。

## 3. 代码组织
- ✅ **模块化**：每个文件只导出一个主要类/函数，避免默认导出混用。
- ✅ **路径别名**：使用 `paths` 配置简化导入路径（如 `@/utils`）。
- ✅ **常量定义**：将魔法数字/字符串提取为 `const` 枚举或常量对象。

## 4. 错误处理
- ✅ **自定义错误类**：继承 `Error` 类，添加业务上下文。
- ✅ **类型守卫**：使用 `is` 关键字进行运行时类型检查。
- ✅ **可选链与空合并**：使用 `?.` 和 `??` 安全访问嵌套属性。

## 5. 性能优化
- ✅ **避免重复计算**：将复杂类型计算结果缓存到变量。
- ✅ **懒加载**：使用 `import()` 动态导入大型模块。
- ✅ **类型擦除**：确保编译后无多余类型代码。
