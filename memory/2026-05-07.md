## 🔧 解决方案
由于 Docker 命令需要 sudo 权限，需要用户手动重启容器：

```bash
cd /home/myuser/searxng
docker-compose restart
```

或者：

```bash
sudo docker restart searxng
```

重启后，SearXNG 应该能够使用国内搜索引擎（baidu, 360search, sogou）进行搜索。
