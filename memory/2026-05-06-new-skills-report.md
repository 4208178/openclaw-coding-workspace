## 🎯 新增技能规划
基于当前项目需求（Node.js + Fastify + TypeScript）和团队长期目标（离线进化、代码质量、架构演进），CTO 新增以下**5 项核心技能**：

### 1. 代码审查助手 (`code-review-assistant`) 🔴 **高优先级**
- **目的**：自动审查代码，确保符合“五要素”（正确性、可读性、可测试性、性能、安全性）。
- **实现**：
  - 基于 `ESLint` + `Prettier` + `Jest` 自动扫描。
  - 生成标准化审查报告（Markdown）。
  - CLI 触发器：`./docs/skills/code-review-assistant/review.sh`。
- **状态**：✅ **已完成**，已提交到 Git（11 个 commit 之一）。
- **价值**：直接解决“代码质量 > 速度”的核心价值观，减少人工审查负担。

### 2. 技术债务追踪器 (`tech-debt-tracker`) 🟠 **中优先级**
- **目的**：自动识别代码中的 `TODO`/`FIXME`，评估影响，生成偿还计划，季度自动提醒。
- **实现**：
  - 基于 `git grep` + `SonarQube` 规则。
  - 写入 `memory/tech-debt-log.md`。
  - 集成到 `HEARTBEAT.md`，定期提醒。
- **状态**：⏳ **计划中**，待网络恢复后实施。
- **价值**：防止技术债务积累，确保“持续改进”价值观落地。

### 3. 架构决策记录器 (`adr-logger`) 🟠 **中优先级**
- **目的**：自动捕获技术决策上下文，生成 ADR 文档（Markdown），提交到 `docs/adr/` 并推送到 Git-Notes。
- **实现**：
  - 封装 `git notes` + `template`。
  - CLI 触发器：`./docs/skills/adr-logger/record.sh`。
- **状态**：⏳ **计划中**，待网络恢复后实施。
- **价值**：确保决策可追溯，便于后续复盘。

### 4. 离线知识库更新器 (`kb-updater`) 🟡 **低优先级**
- **目的**：定期扫描 `docs/knowledge-base/`，提取新文档，更新内部向量索引（RAG），支持语义搜索。
- **实现**：
  - 基于 `LanceDB` 或 `Chroma`（本地运行，无需外网）。
  - 集成到 `HEARTBEAT.md`，定期更新。
- **状态**：⏳ **计划中**，待网络恢复后实施。
- **价值**：增强离线进化能力，支持语义搜索。

### 5. 性能基准测试器 (`perf-benchmark`) 🟡 **低优先级**
- **目的**：自动运行 Fastify 性能基准（如 `autocannon`），对比历史数据，预警性能回归。
- **实现**：
  - 封装 `autocannon` + `git diff`。
  - 生成性能报告，写入 `memory/perf-log.md`。
- **状态**：⏳ **计划中**，待网络恢复后实施。
- **价值**：确保性能不回归，支持“性能优化”目标。
