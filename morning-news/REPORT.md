## 📋 一、项目概述

### 1.1 任务目标
基于 CEO + CIO 联合指令，开发一个**极简晨间速递**服务，实现：
- 天气数据获取与推送
- 盘前金融风向标
- 新闻/热搜速览
- 多渠道推送（邮件/微信）

### 1.2 技术架构
```
技术栈: Node.js + nodemailer + cron + axios
版本: v1.0.0
部署: 本地定时任务
```
